# Dr. Pietro Piombetti — Biologo Nutrizionista

Sito one-page statico (HTML, CSS, JavaScript senza build).

- `index.html` — pagina principale
- `privacy.html` — informativa privacy (bozza da verificare)
- `assets/css/styles.css`, `assets/js/main.js`, `assets/img/`

## Anteprima locale

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File serve.ps1
```

Poi aprire http://localhost:8080.

## Prima della pubblicazione definitiva

- Collegare il modulo di contatto: impostare `data-endpoint` sul form in `index.html` (es. Formspree).
- Confermare indirizzi delle sedi, iscrizione all'Albo, P.IVA e recapiti (vedi commenti `DA COMPLETARE`).
